# 🎮 Portfolio RPG Engine

> A 2D RPG-style interactive portfolio built in C++ using SDL2 and Tiled, designed as a Pokémon-like game where my projects are embedded into the world as interactive in-game elements.

This project is not a traditional portfolio website.
It is a custom-built 2D game engine and interactive experience that showcases my development skills through exploration rather than static presentation.

---

## 🚀 Concept

The idea behind this project is to transform a developer portfolio into a playable experience.

Instead of scrolling through a webpage, users explore a 2D RPG world where:

* each area represents a technical theme or skill
* in-game computers display my projects
* interactions trigger detailed explanations of my work
* the world itself demonstrates my ability to build a custom engine

This project merges:

* game development
* engine design
* interactive storytelling
* technical portfolio presentation

---

## 🎯 Goals

* Build a lightweight 2D engine from scratch using SDL2
* Integrate map design using Tiled
* Create a fully interactive RPG-style navigation system
* Present my projects in an immersive, non-linear way
* Demonstrate low-level C++ architecture and game systems design

---

## ✨ Features

* 🎮 2D top-down RPG exploration (Pokémon-like movement system)
* 🗺️ Map design using Tiled (.tmx support)
* 🧠 Interactive objects triggering project presentations
* 💻 “In-game computer” showcasing external projects
* ⚙️ Custom game engine architecture in C++
* 🎨 Sprite rendering, collision system, and entity management
* 🧩 Modular scene and state management

---

## 🛠️ Tech Stack

* Language: C++
* Graphics: SDL2
* Map Editor: Tiled
* Architecture: custom ECS-like / entity system (in progress)
* Build system: CMake / Makefile

---

## 🧠 What This Project Demonstrates

This project is designed to prove more than just UI or gameplay implementation:

* **Engine design thinking**: building reusable systems instead of scripts
* **Low-level graphics handling**: rendering, events, and game loop management
* **Architecture skills**: separation of systems (rendering, input, logic)
* **Data-driven design**: using Tiled maps instead of hardcoded levels
* **Creative technical integration**: merging portfolio + game design
