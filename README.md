# portflolio
Application représentant le portfolio de Gaston Lions.

Version 1 (en cours) : codée en c++ avec la bibliothèque graphique SDL2
L'idée est de créer une application ouvrant une fenêtre dans laquelle sera affiché un monde 2D style RPG avec un personnage pouvant se déplacer dans un environnement.
Pourra donc servir de présentation de projet (portfolio) mais aussi de bac à sable en ajoutant des fonctionnalités.

## Prochain objectif :

 - Génération 2D d'une scène + moteur :

Revoir la structure actuelle du code pour essayer de créer un petit moteur c++ 2D
Ajouter une fonctionnalité au moteur permettant de lire et charger une map depuis un fichier généré avec l'application Tiled
Afficher la map dans la fenêtre

Ce qui permettra au portfolio doit avoir une fenêtre avec un personnage pouvant se déplacer à l'intérieur d'une map.
Ensuite il faudra lui ajouter un système de colision avec le décors présent dans la map, puis les intéractions afin de commencer à réfléchir à comment mettre en avant les différents projets dans le portfolio -> projet d'école ? projet perso ? Petite fonctionnalité supplémentaire ? etc ...
